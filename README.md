# Drag & Drop Grid System (Xogot Tutorial)

This project demonstrates how to build a **drag-and-drop object system with grid snapping** entirely in **Xogot** — the iPad and iPhone port of the Godot game engine.

The tutorial shows how to create reusable draggable objects that snap cleanly to a grid and avoid overlapping placements. This technique is useful for **level editors, puzzle games, strategy games, and grid-based gameplay systems**, all built directly on iPad.

---

## Features

- Reusable **draggable object scene**
- **Grid snapping** while dragging objects
- Prevents objects from overlapping **occupied grid positions**
- Touch-friendly drag detection using **GUI input events**
- Simple object duplication workflow for creating new items
- Optional **TileMap scenes collection** for fast placement
- Designed to work smoothly on **iPad and iPhone** with Xogot
- Compatible with **Godot 4.x**
